## 3. Obim koji radim (podrazumijevano — javi ako želiš drugačije)

- Paket `nba_engine/` sa jasnim modulima: `config`, `teams`, `utils`, `offer`, `loaders`, `model`, `pipeline`,
  `evaluation`, `schedule`, `history`, `odds_api`, `refresh/*`.
- `app.py` ostaje Streamlit aplikacija sa istim mogućnostima, ali tanka (samo prikaz).
- Jedna komanda: `python -m nba_engine ui | analyze | fetch-offer | refresh`.
- Konfiguracija kroz `.env` (`ODDS_API_KEY`, `NBA_SEASON`, `NBA_DATA_DIR`); sezona se automatski prepoznaje iz postojećih podataka.
- **Model i formule ne mijenjam.** Ispravljam samo očigledne greške i svaku prijavljujem.
- Testovi: regresioni test da nova aplikacija daje ISTE brojeve kao stari `app.py` na stvarnim podacima + jedinični testovi.
- Oporavljene skripte iz VS Code istorije idu netaknute u `archive/`, a sređene u `nba_engine/refresh/`.
- NE radim: ENGINE_REZULTATI, stare „engine“ module iz februara, `filters.py` (crna lista igrača) — ostaju samo u `archive/`.

## 4. Odluke koje čekaju korisnika

2. Ključ za The Odds API je javno vidljiv: predlažem poništiti ga na the-odds-api.com i napraviti novi.
   Novi ključ ide u `.env` lokalno, a u GitHub Secrets (`ODDS_API_KEY`) ako robot treba da nastavi; inače robot da se ugasi.
